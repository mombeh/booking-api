# 🗓️ Appointment Booking API

A RESTful API built with Node.js, Express, and PostgreSQL for managing service appointments between clients and service providers — complete with real-time notifications via WebSockets and auto-generated Swagger documentation.

---

## 🚀 Features

- User registration & authentication (JWT-based)
- Role-based logic: Clients vs. Service Providers
- Time slot creation & booking
- Appointment management (booking, viewing)
- Real-time notifications with **Socket.IO**
- PostgreSQL database with schema initialization
- RESTful design and **Swagger API documentation**

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **ORM/DB Layer**: `pg` with raw SQL queries
- **Authentication**: JSON Web Tokens (JWT)
- **WebSockets**: Socket.IO
- **Logging**: Winston
- **Testing**: Jest (or Node.js test runner)
- **Documentation**: Swagger (OpenAPI 3.0)
